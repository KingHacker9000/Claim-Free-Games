FAQ

Questions people ask before installing.

Short answers for humans, search engines, and anyone evaluating whether the project fits their setup.

What does Claim Free Games do?

It checks the Epic Games Store for current giveaways, compares them with the games already owned by your Epic account, and automatically attempts to claim any free game you are missing.

Is this an automatic Epic Games free game claimer?

Yes. The project is designed specifically to automate claiming time-limited Epic Games Store giveaways. It checks once per day by default and only starts a claim when a current giveaway is not already owned.

Does it store my Epic Games password?

No. You sign in through Epic's own login page. Claim Free Games stores an OAuth session token locally on your device so later checks do not require saving your Epic password.

Can I run it on a Raspberry Pi 5?

Yes. Raspberry Pi 5 is an excellent always-on host. The Pi installer configures the app, Chromium fallback, a once-daily systemd timer, phone alerts, and remote noVNC access when human interaction is required.

Can I run it on Windows, macOS, or Linux instead?

Yes. Desktop builds are available for Windows x64, macOS Apple Silicon, macOS Intel, and Linux x64. The desktop app lives in the system tray and uses native notifications.

Will it send me a notification every day?

No. Routine daily checks stay silent. Notifications are intended for meaningful events: a new unowned giveaway is detected, a game is claimed, a claim fails, or Epic requires you to sign in or solve a CAPTCHA.

Why does it have a browser fallback?

Epic can change checkout behavior or request human verification. Instead of making fragile browser automation the default, Claim Free Games uses an API-first path and opens a real Chromium session only when the normal route cannot complete the claim.

Is this affiliated with Epic Games?

No. Claim Free Games is an unofficial open-source community project and is not affiliated with or endorsed by Epic Games.
